# SOB4ES - Modelado Predictivo de Biodiversidad
### Documentation

Este repositorio contiene los pipelines completos para el entrenamiento, evaluacion y puesta en produccion de los modelos predictivos del proyecto SOB4ES. El objetivo principal del sistema es predecir indices de diversidad biologica (como el indice de Shannon H') a partir de variables edafologicas, climaticas y espaciales.

## Objetivos de la Rama

El objetivo de esta rama es almacenar todo lo relacionado con la documentación de este TFG.

## Contenidos de la Rama

La rama se estructura principalmente alrededor a un template inicial de Typst con el esquema general de la memoria:

* **`MemoriaTFG.typ`:** Plantilla central del TFG.
* **`MemoriaTFG.pdf`:** Última versión de la documentación exportada.
* **`bibliografia.yml`:** Archivo yml donde se almacenan las diferentes fuentes bibliográficas.
* **`media`:** Carpeta donde se almacenan imágenes y la portada de este TFG.
* **`diagramas`:** Carpeta donde se almacenan los diferentes diagramas creados con drawio.
* **`chapters`:** Carpeta en la que se almacenan los diferentes capítulos/secciones de este TFG.
* **`appendices`:** Carpenta en la que se almacenan los diferentes anexos de este TFG.
